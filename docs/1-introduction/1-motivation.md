# Motivation

OpenSherlock lies on a journey starting with a Forth experiment in the 1980s call the Cognitive Companion, to a 1990's powerful AI program, again written in Forth, called The Scholar's Companion (TSC) - which has been transliterated to Java - to the first topic map experiments for machine reading called SolarSherlock - mostly because it used Apache Solr for its database - then renamed OpenSherlock when Solr was replaced, first with Elasticsearch, and now PostgreSQL.

The motiviaiton has always been that of human capabilities augmentation.

TSC proved its value in that context when its human immune system model revealed the reason why a patient with Leukemia was repeatedly visiting the hospital with pneumonia. The model showed that the immune system relies on reactive oxygen molecules to deal with bacterial infections, which immediately contraindicates the use of high dose antioxidanta, sometimes prescribed to patients.

At the time of this writing, we are seeing an outburst of modern AI - by which the reference is to Transformer-based neural nets - showing important abilities in the same context.  Nothing in OpenSherlock's history used neural networks; all of its history is based on *symbolic* AI.

Having said that, we are now engaging neural nets in specific ways, which will be described elsewhere in this document.
